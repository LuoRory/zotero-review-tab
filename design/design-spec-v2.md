# 回顾页面 v2 · 交互与视觉设计规格

配套原型：[review-page-v3.html](review-page-v3.html)。原型里的标题、注释都是占位数据；实现时要对齐的是每个控件的接口调用（§4）。

原型自检：无头 Chromium 在 1440×900、1100×860、760×900 三种宽度下跑过：初始态、选中笔记（右栏渲染）、点注释（中栏高亮）、暗色主题，无控制台报错、无横向滚动。

## 1. 设计原则

1. **默认无感**：打开即算回顾，关闭即完成，页面上没有「提交」按钮。
2. **只在需要时动手**：日常操作只有两个——读完后给一次 FSRS 反馈，或在不想再看时暂停。
3. **不暴露调度细节**：不出现稳定度、难度、复习次数等词，只回答「下次大概什么时候再看」。
4. **连续感优先**：左栏顺序即阅读顺序；完成只改样式、不重排，详情底部给出「下一个」。
5. **中栏就是详情**：不点笔记时中栏就是完整阅读面，右栏只在需要渲染笔记时出现。

## 2. 信息架构

> **实现状态（0.1.11）**：本页三栏结构已实现；右栏新增“PDF 页面”模式（点注释时渲染所在页并叠加选区），注释缩略图与手写批注解析见 §2.3。

```text
顶栏   回顾 | 今日进度 x/y | 剩余 n | 刷新 | 设置
左栏   单元列表（今日 / 全部 + 排序 + 类型筛选 + 搜索）
中栏   单元详情：标题、状态与操作、注释（按页）、笔记索引、反馈、上一条/下一条
右栏   笔记模式：渲染选中笔记；PDF 页面模式：渲染注释所在页
```

### 2.1 三栏

| 栏 | 内容 | 交互 |
| --- | --- | --- |
| 左栏（20%，可拖拽） | 单元列表；今日视图中「需要回顾」的单元标题前有圆点；第二行左为作者、右为注释·笔记数 | 点选切换单元；不计入回顾，是否回顾由反馈决定；重绘后保持滚动位置 |
| 中栏（自适应） | 单元详情：标题（右侧暂停按钮）、元信息（书籍带批次日期）、状态行、笔记索引（可折叠）、注释按页（可折叠）、四档反馈、上一条/下一条 | 点笔记 → 右栏笔记模式；点注释 → 右栏 PDF 页面模式 |
| 右栏（30%，可拖拽） | 有笔记时默认渲染第一条笔记；点注释切换为所在 PDF 页面预览 | 拖拽分隔条调整宽度；关闭：切换单元 |

- 两栏宽度用百分比（默认 20 : 50 : 30），拖拽后按当前比例保存，手柄位于栏交界内。
- 笔记 HTML 必须经过清洗后渲染：白名单标签、去掉 `on*` 属性与 `javascript:` 链接，`a` 加 `rel="noopener"`。
- 注释列表不显示高亮/下划线类型文字，只用色条表达颜色。

### 2.2 时间分隔与筛选

| 控件 | 位置 | 选项 |
| --- | --- | --- |
| 搜索 | 全部视图 | 标题、作者 |
| 类型 | 全部视图 | 全部 / 论文 / 书籍 |
| 排序 | 今日/全部 标签右侧，仅「全部」可见 | 最近活动 / 到期临近 / 内容量 / 标题 |

- 时间分隔只出现在「全部 → 最近活动」，分为 今天 / 近三天 / 近七天 / 更早。今日视图不分隔。
- 圆点只在今日视图出现，表示「需要回顾」；不再表达来源。

字段依据：搜索用 `title`、`creator`；类型用 `unitType`（`article` / `book-session`）；排序用队列顺序、`effectiveDueAt`、`annotationTotal + notes.length`、`title`。
在「全部」中打开单元不计入进度，也不能评分；暂停可以在任意视图操作。

### 2.3 PDF 页面预览与注释图片（0.1.10 / 0.1.11）

| 能力 | 实现要点 |
| --- | --- |
| 页面渲染 | 用 Zotero 自带 pdf.js（`resource://zotero/reader/pdf/build/*`），一次渲染一页，渲染后立即销毁；按 附件/版本/页码 缓存到 `<data directory>/pages` |
| 选区标注 | 按 `annotationPosition`（PDF 点）换算到 pdf.js viewport 比例；注释用自身颜色框出，同页其它注释淡色标出 |
| 段落续行 | 同一段被换行拆开的片段合并为一条并一起高亮 |
| 翻页 | ‹ 上一条 / 下一条 › 在当前页的注释间移动；缩放切换“适应宽度 / 100%” |
| 图片注释缩略图 | 直接引用 Zotero 缓存 `<data directory>/cache/library/<key>.png`，以 `file:` URL 交给 `<img>`，不内联 base64 |
| 区域遮罩 | 缩略图是 4× 渲染后裁出的截图，用同比例的 SVG 遮罩对齐选区；旧缓存过大或选区被调整时都能只显示选区 |
| 手写批注 | 没有缓存图，按笔迹坐标绘制 SVG；手写只按“附件 + 第一笔时间”记一条活动，避免注释数虚高 |
| 悬停放大 | 注释行悬停放大图片；右侧预览包含正文、评论与大图 |
| 缺失缓存 | 明确提示，并仍提供「在 PDF 中打开」 |

pdf.js worker 在 chrome 作用域中需先把 worker 模块注册为 `globalThis.pdfjsWorker`，再导入 `pdf.mjs`，否则会挂起。

## 3. 核心交互模型

### 3.1 完成由 FSRS 反馈决定

- 点选单元只是切换详情，**不计入回顾**。
- 只有点击详情最下方的四档反馈（没记住 / 困难 / 继续 / 容易，对应 Again / Hard / Good / Easy）才记为今天已回顾，并更新该单元的下次到期。
- 反馈调用 `gradeUnit(id, rating)`，返回值 `{ card, log }` 中的 `card.effectiveDueAt` 直接用于状态文案，不在页面内自行推算。
- 统计口径：`今日进度 = 今日队列中已反馈 / 总数`。
- 「全部」视图不可评分（不显示反馈按钮，键盘 1–4 也不生效），但**保留暂停按钮**，方便在全局浏览时直接把不想看的单元移出回顾。

### 3.2 反馈后的行为

| 行为 | 说明 |
| --- | --- |
| 自动跳转 | 反馈成功后立即切到下一条**未反馈**的队列单元；没有则停在本条 |
| 再次点击撤销 | 回到已反馈单元时，原档位保持高亮；再点同一档即撤销，恢复为未反馈并回退页面内的排期显示 |
| 改选其他档 | 点击另一个档位视为改评，替换原记录，不新增一条 |
| 键盘 | `1`–`4` 直接对当前单元反馈，效果与点击相同 |

- 撤销只在本次会话内可靠；`gradeUnit` 写入调度后，真正的回滚需要后端支持，见 §6。

### 3.3 暂停（Suspend）

- 详情标题右侧只有一个图标按钮：⏸ 暂停 / ▶ 恢复，对应该单元的 `paused`（Suspend）。
- 暂停后单元**仍留在列表里**，只是变淡；不计入顶栏进度与反馈区的位置计数（分母随暂停/恢复变化），也不会被自动跳转到。
- 今日与「全部」两个视图的标题右侧都有这个按钮，含义一致，恢复也在同一位置。
- 暂停中的单元自身在「今日」里不显示位置计数（它不在分母里）。
- 「全部」里不显示「已暂停」等状态字样，只靠变淡与按钮图标表达。

### 3.4 今日队列的顺序

- 今日列表**固定按 FSRS 推荐顺序**排列，不提供排序控件。
- 排序控件只在「全部」视图显示（最近活动 / 到期临近 / 内容量 / 标题）。
- 反馈不会改变列表顺序，只会改变该行的完成样式。

### 3.5 状态文案（中栏标题下的一行，只出现一条）

| 情况 | 文案 | 数据 |
| --- | --- | --- |
| 正常 | 「下次大约 {n} 天后」 | `effectiveDueAt` 与今天的天数差 |
| 已到期 | 「该看了」 | `effectiveDueAt <= now` |
| 已暂停 | 「已暂停」 | `paused` |
| 已反馈 | 「已反馈：{档位} · 约 {n} 天后再看」 | 今日反馈记录 + `gradeUnit` 结果 |
| 未入队 | 「还没开始」 | 无 `fsrsCard` |
| 全部视图 | 不显示任何状态文案 | — |

**注意**：到期判断必须用 `effectiveDueAt <= now`，不要用「天数差 == 0」，否则会出现「约 8 天后」与「到期」自相矛盾的文案。

**文案克制**：不写「反馈后会跳到下一条」「按 1–4 也可以」「只读查看 · 评分只在今日」这类操作说明小字。信息由控件本身和状态行表达。

### 3.6 同步与刷新（0.1.11 起）

| 层 | 触发 | 范围 |
| --- | --- | --- |
| 局部重建 | Zotero Notifier：笔记 / 注释 / 手写批注的 add、modify、delete；父条目 modify | 只重建受影响的父条目；删除时用运行期登记的 `childID → parentKey` 回溯归属 |
| 视图重绘 | 标签页重新获得焦点，且版本号变化或标记为过期 | 不扫库；无变化时直接返回，避免闪动 |
| 全量重建 | 顶栏「刷新」按钮 | 重扫个人库，保留评分 / 日志 / 暂停状态，清理失效队列引用 |

- 增量同步**不在后台重绘**，避免打断正在编辑笔记或阅读的用户。
- 删除判定：重建后该父条目下没有出现在新分组里的单元即已无来源，删除并同步清理队列引用。
- 父条目被删除或类型变得不可回顾（如论文改成软件）时，移除其名下全部单元。
- 知识边界：`childID → parentKey` 只在运行期保存，重启后若删除的是笔记/注释，可能找不到归属；此时用「刷新」兜底。

## 4. 接口映射

| 控件 | 接口 | 说明 |
| --- | --- | --- |
| 今日列表 | `getDashboard()` | `units` 按队列顺序，带 `reviewedToday`、`queueRating`；暂停/非论文书籍类型已过滤 |
| 全部列表 | `getRecentUnits({ offset, limit, sort })` | 分页，`hasMore` 决定「加载更多」 |
| 选中单元 | `getUnit(id, { annotationOffset, annotationLimit })` | 详情、笔记、注释；`excluded: true` 表示类型不可回顾 |
| 加载更多注释 | `getUnit` 追加 | 用 `hasMoreAnnotations` 判断 |
| 四档反馈 | `gradeUnit(id, rating)` | 返回 `{ card, log }`，用 `card.effectiveDueAt` 显示下次到期 |
| 撤销反馈 | `undoTodayRating(id)` | 仅当天有效 |
| 暂停 / 恢复 | `setUnitFlag(id, { paused })` | 任意视图可用 |
| 全量刷新 | `refreshAllContent()` | 并让打开的标签页重绘 |
| 窗口重绘判断 | `stateRevision()` / `clearViewsStale()` | 标签页获得焦点时决定是否重绘 |
| 在 PDF 中打开 | `openAnnotation(key, tabID)` | 会自动回切到回顾页 |
| 打开 / 新建笔记 | `openNote(key)` / `newNote(parentRef)` | |
| 设置 | `openPreferences()` | |

### 4.1 状态行数据

- 真值：`fsrsCard.effectiveDueAt`、`lastReviewedAt`、`paused`。
- 文案里的「约 N 天后」由 `effectiveDueAt` 与今天日期差得出，不要求精确到小时。
- 到期判断用 `effectiveDueAt <= now`。


## 5. 视觉规格

### 5.1 界面基线（贴近 Zotero 界面）

- **尺寸一律用相对单位**：字号、间距、最小点击区都用 `rem`，不用 `px`。字号跟随 Zotero 界面缩放，在高 DPI 和小屏上不会挤成一团。
- 基础字号 `1rem`（16px，上一轮整体上调），次要文字 `0.9375rem`，分组标题 `0.8125rem`。不按视口缩小字号。
- 圆角只用 3 / 4 / 6px 三档；控件最小高度 24px（`1.5rem`），满足可点击。
- 颜色全部走 Zotero 变量：`--fill-primary`、`--fill-secondary`、`--fill-tertiary`、`--fill-quaternary`、`--text-primary`、`--text-secondary`、`--text-tertiary`、`--accent-blue`、`--accent-green`、`--border-color`。
- 字体：正文用 `font: menu` 继承 Zotero 界面字体；**不用**衬线体做标题，保持与 Zotero 一致。

> 说明：Zotero 7 的完整变量表未能从公开文档核实（文档站不可访问），上面这些是现有插件代码已使用的变量。实现时请以 Zotero 7 实际渲染为准逐项确认，缺失的变量要有回退值。

### 5.2 布局与响应

| 宽度 | 布局 |
| --- | --- |
| 任意宽度 | 三栏：左 20% + 中自适应 + 右 30%（百分比，可拖拽；不再做小屏单列） |
| 56–70rem | 右栏空闲时隐藏；选中笔记时右栏出现，中栏让出宽度 |
| 30–56rem | 单列：列表 → 单元详情 → 笔记渲染，整页滚动 |
| < 30rem | 顶栏进度条隐藏 |

- 小屏下各栏不横向溢出：标题与作者允许换行。
- 「下一个」在小屏下标题独占一行，按钮在下一行。

### 5.3 颜色与表达

| 元素 | 表达 |
| --- | --- |
| 需要回顾 | 只在今日视图：标题前 6px 蓝点；完成后消失 |
| 时间分隔 | 普通小标题（今天 / 近三天 / 近七天 / 更早），只出现在「全部」视图 |
| 已反馈 | 标题降到 `--text-tertiary` 且字重 400；**不用删除线**，不改位置 |
| 已暂停 | 整行降透明度 |
| 选中单元 | 整行实心高亮（`--accent-blue` 底 + 白字）；不用侧边条 |
| 注释 | 仅用 3px 色条表达颜色；不显示「高亮 / 下划线」等类型文字 |

### 5.4 排版

- 左栏单元行两行：标题（省略号）+ 第二行 `作者 [左] · 注释数 · 笔记数 [右]`。
  - 数量统计用 `annotationTotal` 与 `notes.length`，格式固定为 `{注释} · {笔记}`，数字用 `tabular-nums`，`title` 提示写全「注释 N 条 · 笔记 M 条」。
  - 作者会被挤压省略，数量统计不换行、不被压缩。
- 中栏：页码小标签、注释正文两到三行截断、评论一行截断；笔记索引单行标题。
- 右栏笔记渲染：字号 1rem / 行高 1.7；标题按 h1–h4 降级；代码、表格、引用、图片各有样式。
- 空态、加载、错误都用一行文字，不使用大插图。

## 6. 接口现状（0.1.11）

以下能力已实现，供后续维护参考：

- `getDashboard()` 返回 `units[].reviewedToday` 与 `queueRating`，刷新后仍能区分「今天已反馈」。
- `setUnitFlag(id, { paused, stopped, priority })`：暂停/恢复入口。
- `undoTodayRating(id)`：撤销当天的反馈（回退 `fsrsCard`、置空队列项、扣回统计）。
- `refreshAllContent()`：全量重建并让打开的标签页重绘；`stateRevision()` / `clearViewsStale()` 供视图判断是否需要重绘。
- `hydrateUnit()` 笔记带 `title`；非论文/书籍类型返回 `excluded: true`，由 `getDashboard` / `getRecentUnits` 过滤。
- 注释图片相关：`annotation-image.js` 提供坐标解析、区域遮罩、片段匹配等纯函数，`annotation-image.test.js` 覆盖。

仍未做：`getSettings()`（顶栏不显示每日上限）。

## 7. 边界与状态

| 场景 | 行为 |
| --- | --- |
| 首次建档 | 顶栏 + 一行「正在整理笔记与注释…」，不渲染空列表 |
| 今日为空 | 左栏「今天没有需要回顾的内容」；中栏不显示任何单元 |
| 单元被暂停 | 仍留在今日列表（变淡），不计入进度分母，详情显示「已暂停」 |
| 已暂停后打开 | 「全部」中可见并变淡，可直接点标题旁的 ▶ 恢复 |
| 父条目已删除 | 标题显示「已删除的 Zotero 条目」，禁用新建笔记与逐条浏览 |
| 无笔记 / 无注释 | 各用一行空态文字 |
| 注释缓存图缺失 | 提示缓存缺失，仍提供「在 PDF 中打开」 |
| 加载/操作失败 | 行内错误条或 toast + 可重试，不弹窗 |

## 9. 实现约束

- `ReviewTabView` + vanilla DOM，不引入框架。
- 笔记渲染：必须先清洗再写入 `innerHTML`，不允许把 `note.html` 原样拼进 DOM。
- 注释、评论、标题等纯文本一律 `textContent`。
- 不改同步状态 schema 的既有字段语义；新增字段需在 `docs/zotero-data-boundary.md` 里说明。
- 键盘监听放在标签页根节点，避免影响其它窗口。
- 纯逻辑（发现、队列、FSRS、单元维护、注释图片）不得依赖 Zotero / DOM，以便在 Node 中测试。

## 10. 已知遗留项

1. **撤销反馈只对当天有效**：`undoTodayRating` 依赖当天的队列项；历史不可撤销。
2. **删除归属映射只在运行期**：重启后删除笔记/注释可能找不到父条目，需用「刷新」兜底；若要更稳，可把 `childKey → parentKey` 持久化到同步状态。
3. 1100px 左右三栏同时出现时中栏偏窄，可考虑限制右栏最小宽度或改为覆盖式。
