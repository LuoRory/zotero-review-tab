## 一句话概括当前设计

三栏：**左**选单元（今日队列，圆点表示待反馈）；**中**是单元详情（笔记索引、按页注释、四档 FSRS 反馈、上一条/下一条、标题右侧暂停）；**右**栏双模式——选中笔记时渲染笔记，点注释时渲染该注释所在的 PDF 页面并框出选区。**没有“打开即回顾”**，只有四档反馈后才计入进度。

## 版本演进（便于追溯为什么这样设计）

- `review-page.html`：两栏 + 条目级「已回顾/稍后」+ 四档评分。问题：条目级状态与单元级 FSRS 冲突；调度细节暴露太多；「生成单元笔记」越界。
- `review-page-v2.html`：改为单元级四档评分，右栏详情 + 沉浸式浏览。
- `review-page-v3.html`：去掉调度术语，改为三栏，笔记单独渲染。
- 实现（0.1.7–0.1.11）：显式四档反馈、暂停、全量刷新、局部同步、三栏可拖拽；0.1.10 起加入注释图片缩略图与区域遮罩，0.1.11 起右栏加入 PDF 页面预览。

## 已知遗留项

见规格第 10 节，摘要：

1. 撤销反馈只对当天有效。
2. 删除归属映射只在运行期保存，重启后删除笔记/注释需用「刷新」兜底。
3. 1100px 左右三栏偏窄，可考虑限制右栏最小宽度或改为覆盖式。
